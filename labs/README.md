# Labs

Practical, asynchronous lab modules release every week and cover the hands-on side of the course. The homework assignments lean heavily on them, so lab work is kept here where the assignments can reference it.

## Layout

Add one directory per lab as it releases, named by week, for example `week01/`, `week02/`. Keep notebooks, scripts, and notes for that lab together inside its directory.

## Scope

Labs run from week 1 through the end of the course. The later labs introduce AWS Academy for the cloud and deployment topics. Anything that needs cloud credentials follows the secret-handling rules in [`../CONTRIBUTING.md`](../CONTRIBUTING.md): credentials never get committed.
