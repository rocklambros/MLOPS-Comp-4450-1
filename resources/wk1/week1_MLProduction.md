# Advanced Topic: MLOps Week 1

## ML in Production System

## Why is it so important?

- Massive growth in funding, hiring, & enterprise spend shows ML is no longer 'research only'
- ML has transitioned from a research-focused discipline to a core component of modern software applications and business processes
- Models power search, fraud detection, personalization, supply-chain planning, and more
- ML capability has become a key competitive differentiator for modern products

## Building ML Products is Challenging

- 87 % of ML projects stall; 53 % never leave the lab (industry surveys).
- Success demands more than an accurate model:
- Reliable & secure data pipelines
- Robust software around the model
- Safety, fairness, and compliance guards
- Scalable deployment & monitoring
- Result: Shipping ML is a full-stack engineering problem that spans data science, DevOps, and product.

## Enter MLOps

- MLOps = practices & tooling to manage the end-to-end ML lifecycle.
- Version data, code, & models
- Automate training, testing, & deployment
- Monitor performance & drift in production
- Goal: Turn research breakthroughs into reliable, real-world products.

## 3 ML Product Archetypes

Three archetypes define how ML products interact with real-world use cases:

1. Software 2.0 use cases : Taking something that software or a product does in an automated fashion today and augmenting its automation with machine learning. E.g. Github Copilot
2. Human-in-the-loop systems: When automation is not currently deployed - but where humans could have their judgment or efficiency augmented. E.g. Medical Image diagnosis
3. Autonomous systems: Systems that apply machine learning to augment existing or implement new processes without human input. E.g. Self-driving cars
