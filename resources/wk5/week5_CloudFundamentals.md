# Cloud Computing Fundamentals

## Fundamentals

- On-demand delivery of IT resources over the internet
- Organizations rent computing resources from providers on asneeded basis
- Users can quickly access shared resources (like servers or storage) via the network without heavy upfront investments

## Key Features of Cloud

- On-Demand Self-Service → Provision resources automatically
- Broad Network Access → Services accessible over the network from any locations
- Resource Pooling → Pools computing resources to serve multiple; Data and environments remain isolated
- Rapid Elasticity → Scale up or down quickly to meet demands; infinite capacity
- Measured Service → Metering usage and providing transparency

## Why do we care?

- Scalability & Elasticity:
- Businesses can scale their apps easily
- Scale servers up and down based on demand, conveniently
- Cost Efficiency:
- Pay for resources only that we use
- Global Availability:
- Major providers have data centers all around the world
- Deploy services closer to customers
- Reduced Maintenance Burden:
- Frees up focus to work on higher-level tasks
