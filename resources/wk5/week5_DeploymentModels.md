# Cloud Deployment Models

## Public Cloud

- Infrastructure is owned and operated by 3rdparty; shared among multiple customer organizations
- E.g., AWS, Azure, and GCP -their data centers host resources for many customers concurrently
- The greatest scalability and cost-efficiency
- Security and isolation are achieved logically
- Ideal for general workloads, startups, even big companies use it

## Private Cloud

- Infrastructure operated solely for a single organization
- Offers computing benefits in isolated environment
- On-premises → in organization's own data center,
- Hosted by a 3 rd party → dedicated hardware for the org
- E.g., VMware on DU, Azure Stack Hub
- Provide greater control and security
- Suitable for organizations with sensitive data or strict compliance needs

## Hybrid Cloud

- Connectivity enabling Public <> Private data and application portability
- E.g., sensitive/critical work on private, web front-ends managed by public
- Best of both worlds -control/security of private & flexibility/cost of public
- Proper networking required for both to work together
- Brings increased complexity along
