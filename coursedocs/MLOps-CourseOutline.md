# Advanced Topic: MLOps Week 1

## Course Outline

## Learning Goals

1. Design and implement end-to-end machine learning productions systems, from initial conception through deployment and monitoring
2. Understand the core principles and practices required for productionizing ML apps
3. Shift fro m ' model-centric ' mindset to ' system-wide ' design and focus on solving organizational needs
4. Cover the prerequisites for designing ML systems: Web Apps, Cloud, Database, MLOps and SWE principles

## Prerequisites

- Solid understanding of core Machine Learning concepts (classification, regression, evaluation metrics)
- Proficiency in Python programming
- Foundational knowledge of Databases (SQL and basic concepts)
- Familiarity with Git for version control
- No prior experience in web development, cloud computing, or production deployment is assumed
